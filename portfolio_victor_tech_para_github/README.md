# Site de portfólio - Victor Tech

Site responsivo e sem dependências. Abra `index.html` no navegador para visualizar.

## Publicação no GitHub Pages
1. Crie um repositório (por exemplo, `portfolio-victor-tech`).
2. Envie `index.html` e `favicon.svg` para a raiz da branch principal.
3. Em **Settings > Pages**, selecione **Deploy from a branch**, `main` e `/ (root)`.
4. Aguarde a publicação e teste os links.

## Antes de publicar / enviar
- **Confirme** se `https://www.instagram.com/victor_tech/` corresponde ao seu perfil profissional. O nome do perfil foi fornecido em conversas anteriores, mas a URL não foi validada.
- O repositório público `https://github.com/victor-7-7-7/Site_Pagels` foi confirmado.
- O link público da Pagels foi informado como `https://pagelsjiujitsu.com.br/`, mas a disponibilidade do endereço não pôde ser verificada nesta preparação.
- Se quiser, acrescente e-mail comercial, WhatsApp e imagens reais dos projetos; isso vai fortalecer a apresentação.
- AurumFlow, MeuFiado e site de casamento estão identificados como **em desenvolvimento**; não anuncie funcionalidades planejadas como se estivessem prontas.
- As imagens dos cards são **ilustrações conceituais produzidas em HTML/CSS**, não capturas dos projetos.

## Personalização
Edite os textos e links diretamente em `index.html`. Layout e comportamentos estão no mesmo arquivo para facilitar o uso sem build.
